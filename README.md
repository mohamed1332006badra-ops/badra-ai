# BADRA AI — Where AI Works, You Thrive 🚀
### نظام تشغيل وإدارة الأعمال الذكي | AI-Powered Business Operating System

**BADRA AI** هو نظام تشغيل شامل وعصري لإدارة الأعمال والمؤسسات الناشئة والمتوسطة، يجمع بين إدارة علاقات العملاء (CRM)، مسار الصفقات والمبيعات (Deals Pipeline)، إدارة المشاريع والمهام (Projects & Kanban)، التحليلات المالية المتقدمة (Analytics)، وأتمتة العمليات (Automations)، مع مساعد ذكاء اصطناعي تفاعلي يقدم تحليلات وتوصيات مباشرة لنمو أعمالك.

---

## 🌟 المميزات الرئيسية | Key Features

1. **المساعد الذكي (AI Business Assistant):**
   - محادثة تفاعلية مباشرة مع محرك الذكاء الاصطناعي لتحليل الأداء واقتراح القرارات.
   - عرض متقدم للجداول والبيانات وقوائم المهام المنسقة داخل المحادثة.
   - اقتراحات سريعة لأسئلة الأداء والمبيعات والعملاء الأكثر ربحية.

2. **إدارة علاقات العملاء والصفقات (Smart CRM & Pipeline):**
   - متابعة العملاء المحتملين (Leads) وتقييمهم بدرجات الجودة (Lead Scoring).
   - لوحة كانبان تفاعلية لإدارة مراحل الصفقات (New, Contacted, Qualified, Proposal, Negotiation, Won, Lost).
   - سجل نشاط العملاء، الإيرادات المتوقعة، وتصنيفات العملاء المهمين (Tags).

3. **إدارة المشاريع والمهام (Projects & Task Kanban):**
   - نظرة عامة على تقدم المشاريع ونسب الإنجاز وتواريخ التسليم.
   - لوحة كانبان للمهام (To Do, In Progress, Review, Done) مقسمة حسب الأولوية.

4. **التحليلات والتقارير المالية (Analytics & Reports):**
   - رسوم بيانية تفاعلية للإيرادات والمصروفات وصافي الأرباح شهرياً (Area & Bar Charts).
   - تحليل مسار المبيعات (Sales Funnel) ومعدلات التحويل بين المراحل.
   - توليد وتصدير تقارير أعمال ذكية بنقرة زر واحدة.

5. **أتمتة الأعمال وسير العمل (Automations):**
   - إنشاء ومتابعة مسارات العمل التلقائية (Triggers, Conditions, Actions).
   - إحصائيات دقيقة لمعدلات النجاح والوقت الموفر للمؤسسة.

6. **دعم ثنائي اللغة كامل (عربي / إنجليزي) وضبط الاتجاه (RTL / LTR):**
   - دعم التبديل الفوري بين اللغتين (العربية والإنجليزية) بنقرة زر من الشريط العلوي.
   - ضبط اتجاه النصوص والشريط الجانبي تلقائياً (`dir="rtl"` و `dir="ltr"`).
   - دعم خط **Cairo** المتميز للنصوص العربية و **Inter / Sora** للإنجليزية.

## 💻 التقنيات المستخدمة | Tech Stack

- **الواجهة الأمامية:** React 18, TypeScript, Vite.
- **التنسيق والتصميم:** Tailwind CSS, PostCSS, Glassmorphism & Modern Dark Theme.
- **الخطوط:** Cairo (عربي), Inter, Sora.
- **الأيقونات:** Lucide React.
- **الرسوم البيانية:** Recharts.
- **الإشعارات:** Sonner.
- **التوجيه والمسارات:** React Router DOM v6.

## 🚀 التشغيل المحلي | Local Development

1. **تثبيت الحزم التابعة:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   التطبيق سيعمل مباشرة على: [http://localhost:8080](http://localhost:8080)

3. **بناء النسخة الإنتاجية:**
   ```bash
   npm run build
   ```

## 🌐 النشر على Vercel | Deployment

المشروع مزود بملف `vercel.json` جاهز لضبط توجيه تطبيقات الصفحة الواحدة (Single Page Application SPA Rewrites) لتجنب أخطاء 404 عند تحديث الصفحات الداخلية:

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```
